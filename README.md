# Bricks-game: Pure Java Logic & Infrastructure Reconstruction

> **"NHN 부트캠프 과제의 틀을 넘어, 프로젝트 환경 설정부터 로직까지 독자적으로 재구축한 기록"**

## 📖 프로젝트 개요
NHN 부트캠프 과정 중 진행한 '벽돌 깨기' 게임 프로젝트입니다. 단순히 제공된 환경 위에서 코드를 작성하는 것에 그치지 않고, **프로젝트 초기 생성부터 환경 설정(Maven/pom.xml), 클래스 설계까지 모든 인프라를 직접 구축**하여 구현했습니다.

---

## 기술적 설계 및 구현 상세

### 1. 객체 지향적 설계 (Java OOP)
* **GameObject 추상 클래스**: 좌표(`x`, `y`)와 크기(`width`, `height`)를 가지는 모든 게임 객체의 공통 속성을 상속 구조로 관리하여 코드 중복을 최소화했습니다.
* **Paintable 인터페이스**: 화면에 그려지는 모든 객체의 `draw()` 메서드를 일관되게 관리하는 구조를 설계했습니다.
* **컴포넌트 독립성**: `Ball`, `Paddle`, `Bricks`를 독립적인 클래스로 설계하여 객체 간의 메시지 통신을 구현했습니다.

### 2. 물리 엔진 및 게임 루프
* **순수 알고리즘 충돌 판정**: 외부 라이브러리 없이 사각형 영역과 원형 객체 간의 좌표값 비교를 통한 `colliding()` 메서드를 직접 구현했습니다.
* **동적 레벨 시스템**: 스테이지 클리어 시 `multiplySpeed()`를 호출하여 공의 속도를 1.1배 증가시키는 등 게임 엔진의 핵심 로직을 설계했습니다.

### 3. 학습 지향적 코드 작성 (Detailed Documentation)
* **주석을 통한 로직 분석**: 코드 곳곳에 각 메서드와 변수의 역할, 그리고 물리 연산의 원리를 상세히 기록했습니다. 
* **이유**: 단순히 동작하는 코드를 복사하는 것이 아니라, **"왜 이 수치가 필요한지", "이 조건문이 검사하는 바가 무엇인지"** 스스로 완벽히 이해하기 위해 기록하며 개발했습니다.
* **성과**: 복잡한 게임 루프 속에서 공의 반사 방향(`dx`, `dy`)과 좌표계의 관계를 명확히 정의하여 유지보수 효율을 높였습니다.

### 4. AI 협업을 통한 로직 검증 및 학습 (AI-Assisted Development)
* **자기 주도적 학습**: 프로젝트를 바닥부터 구축하며 마주한 기술적 한계(예: JavaFX의 렌더링 생명주기, 물리 충돌 공식의 정밀도 등)를 해결하기 위해 AI를 적극적으로 활용했습니다.
* **검증과 소화**: AI가 제시한 코드를 그대로 복사하기보다, **구현된 로직이 왜 그렇게 작동하는지 주석을 달며 역으로 분석**하고 제 프로젝트 환경에 맞춰 최적화했습니다.
* **성과**: 복잡한 예외 상황(공이 벽과 패들 사이에 끼는 현상 등)에 대한 해결책을 AI와 토론하며 도출해냈고, 이 과정을 통해 **"모르는 것을 빠르게 찾아내어 내 실력으로 만드는 법"**을 익혔습니다.

## 🔍 코드 속의 디테일 (Example of Analysis)

* **물리 좌표계 이해**: `// 컴퓨터 그래픽 좌표계는 천장에 가까우면 - / 멀면 +`와 같이 입문자가 흔히 헷갈릴 수 있는 윈도우 좌표계를 주석으로 명시하며 작업했습니다.
* **객체 간 상호작용**: `// 블록이 깨졌나 안 깨졌나 차이 alive = true -> 살아있음 false -> 블록 죽음` 등 상태 값에 따른 로직 변화를 직관적으로 관리했습니다.

## 기술적 서사: "오해를 성장의 기회로 바꾼 기록"

### 환경 설정의 독립성 (Build from Scratch)
* **도전**: 과제 가이드라인을 독자적으로 해석하여, 기존 프레임워크(`World` 등)를 단순히 사용하는 방식 대신 **아예 새로운 프로젝트를 생성**했습니다.
* **해결**: 라이브러리를 단순히 호출하는 편한 길 대신, `pom.xml` 설정부터 JavaFX 애니메이션 타이머 활용까지 모든 빌드 인프라를 직접 구축했습니다.
* **성과**: 이 '삽질'을 통해 자바 프로젝트의 **빌드 경로(Build Path)와 클래스 패스** 등 자바 시스템의 근본적인 메커니즘을 완벽하게 이해하게 되었습니다.

## 💡 Lessons Learned
* "남이 깔아준 판이 없어도 스스로 시스템을 구축할 수 있는 **자생력**을 키웠습니다."
* "환경 설정의 오류와 싸우며 얻은 데이터는 결코 배신하지 않는다는 확신을 얻었습니다."
* "이때 얻은 자신감은 이후 **디스코드 봇을 SQL 기반 웹 서비스로 마이그레이션**하는 복잡한 프로젝트를 성공시키는 원동력이 되었습니다."
